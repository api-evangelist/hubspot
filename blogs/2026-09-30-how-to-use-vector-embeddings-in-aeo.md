A vector embedding is a numerical representation created by an embedding model. The model converts text into a list of numbers that can be compared with other vectors, helping a retrieval system find passages with similar meaning even when they use different words. Semantic retrieval is one tool AI systems can use to find source material; modern retrieval can also combine semantic search with keyword search and other relevance signals.
